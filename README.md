# exodus — ready-to-upload static site

This repository contains a static single-page demo wallet named "exodus". It is a ready-to-upload static site (no build step required).

How to use
1. Download the repository as a ZIP from GitHub: https://github.com/thegoodplayyerfsfsfsfs-cmd/exodus-site
2. Upload the repository files to your static host (or extract and upload contents of the repository root).

Optional: replace branding/logo.png with your own logo file to show it in the header.

Notes
- The site stores wallet data in localStorage on your device.
- This is a client-side static demo: it does not connect to real networks by default.
